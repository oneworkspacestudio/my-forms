# Shared sign-in repair

A valid Forms session could exist without a Workspace session. The portal then
rejected author API calls; the retry link re-entered Forms OIDC and repeated the
same state. Author sign-in now enters through Workspace. A portal-specific 401
automatically reconnects once through Workspace, retaining the editor/respondent
route. Ordinary app errors never trigger this redirect. The retry guard clears
after successful gallery access. Regression tests reproduce the split-session
response and verify the shared entry point and bounded reconnect.

Published preview2, promoted public channel, and installed via normal protected
update. Public JavaScript bytes match source and readiness/update checks pass.
No phone-browser or visual verification is claimed.
